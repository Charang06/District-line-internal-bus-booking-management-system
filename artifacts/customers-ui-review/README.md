# Customers page UI review

Implemented locally on `ui/customers-page-handover`. Changes remain uncommitted. Nothing was merged or deployed. Earlier Staff, typography and release-candidate work was preserved.

## Exact source and test files changed

| File | Change |
| --- | --- |
| `src/App.jsx` | Mount the Customers presentation component and expose Customers-specific loading/error/retry state through the existing request loader. Both analytics memo bodies, period states and date logic remain identical to the pre-task source. |
| `src/components/CustomersPage.jsx` (new) | Compact navy page header, section icons, independently controlled period selectors, route comparison cards, accessible departure lists, regular-customer table, count badge and explicit loading/error/empty states. |
| `src/components/CustomersPage.css` (new) | Customers-scoped navy/white/gold styling, inherited global Inter, responsive route cards, keyboard focus, readable labels, tabular numeric columns and contained horizontal table scrolling. |
| `src/data/customerAnalytics.test.js` (new) | Five frontend tests exercising the existing App memo bodies directly, without moving or duplicating the production formulas. |
| `scripts/customers-ui-browser.cjs` (new) | Synthetic analytics fixtures, isolated browser checks and before/after screenshots using the existing browser harness. |

`dist/` was regenerated by Vite. [manifest.json](manifest.json) lists exact source changes and generated review files. `baseline-source/` preserves the original App and customer calculation source; `baseline-build/` preserves the pre-task static build. `task-changes.patch` shows this task's App changes, separately from the earlier working-tree changes.

## Preserved rules and remaining limits

The original frontend calculations are byte-identical. Server-side normalized-mobile grouping, confirmed-booking restrictions and deduplication by trip remain unchanged. The UI tests receive synthetic pre-aggregated regular-customer profiles matching that API contract; they do not execute the PostgreSQL aggregation query. The frontend tests verify downstream period filtering, rankings, distinct-month counts and recent-trip dates against the actual unchanged memo bodies.

Backend source, API definitions, database schema, migrations, RLS/grants, authentication, MFA, rate limiting, permissions, backup configuration and environment variables were not changed. Staff and Accounts source, global typography/styles, and shared navigation/footer markup are unchanged. No Home, Log, Info, Dashboard, booking, cargo or finance behavior was redesigned.

No known visual or functional failures remain in the tested paths. Live API/database integration, physical devices and manual screen-reader checks were not performed. This is a local, mocked regression review rather than a production deployment or pixel-diff certification against an external reference image.

The browser wrapper reuses the existing `scripts/staff-ui-browser.cjs`, `scripts/security/browser-local.cjs` and `artifacts/ui-refresh-review/browser-check.cjs` without changing their source.
