# Typography review

Inter is self-hosted from the official rsms/inter repository under the included SIL Open Font License. One WOFF2 variable file supplies normal UI weights 400, 500, 600 and 700; preload and font-display: optional avoid a late font swap. Slow first loads may retain the system fallback for that page view.

- src/index.css
- src/App.css

- src/components/RecoveryEmailVerification.css

- public/Inter-LICENSE.txt (added)

Visual differences: Inter replaces system, serif and monospace faces throughout the frontend and print styles. Page titles use 700, section headings and buttons 600, labels/navigation 500, and body text 400?500. Former extra-heavy emphasis uses 600. Financial/count displays and tables use tabular digits. Font metrics may change text wrapping. Calendar date buttons lose their default horizontal padding so two-digit dates fit at tablet widths; grid dimensions and spacing remain unchanged. Existing colors, images, font sizes, component dimensions and application logic are preserved.

Validation: npm.cmd run build passed; npm.cmd run lint exited 0 with existing repository warnings. 58/58 isolated browser checks passed using synthetic API responses. Typography checks cover login, all administrator navigation tabs and staff tabs at 360, 768 and 1440 pixels, loaded Inter, supported weights, page overflow, horizontally clipped button text and tabular tables. Existing regressions additionally cover booking/cargo validation and submission, Add Bus, Trip Controls, navigation and login at 390 pixels. Mobile login and desktop dashboard screenshots were visually inspected. These are synthetic smoke/regression checks, not pixel-diff comparisons or exhaustive checks of every settings dialog, populated ledger or print output.

No deployment or real API writes were performed. Pre-existing workspace changes were left intact. dist/ was regenerated by the build.
